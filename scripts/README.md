# DevRack Scripts

Collection of scripts utilized throughout and with my home server: Alexandria.

Note scripts may require updates of paths and variables to use on your own setup.

## Docker Scripts

These scripts are used with dockers running on Alexandria. (Unraid based)

## Weather-Alert

Script that monitors NOAA weather alerts to then take action based on weather alert.

## BackBlaze Scripts

Scripts to support backing up Alexnadria to cloud solution.

## Windows 11

Scripts leveraged when updating to Windows 11 across multiple devices to re-create Alexandria network shares.

### Others

#### backup-offsite-all-alexandria.sh

Is written to leverage my offsite backup.
